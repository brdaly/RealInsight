# Security policy

## Supported code

Security fixes are applied to the current `main` branch. This portfolio
demonstration does not promise support for older commits, forks, or deployments.

## Report a vulnerability privately

Do not open a public issue or discussion for a suspected vulnerability.

After GitHub private vulnerability reporting is enabled, use the repository's
**Security → Advisories → Report a vulnerability** form:

<https://github.com/brdaly/RealInsight/security/advisories/new>

If that form is unavailable, use <https://dalyventures.com/> to request a secure
reporting channel. Do not send secrets, exploit payloads, personal data, or
confidential property information through a public form.

Include a concise description, affected path or commit, reproduction steps,
impact, and any suggested remediation. Share only the minimum test data needed
to reproduce the issue.

The maintainer will acknowledge reports when practical, validate the issue,
and coordinate disclosure after a fix. No response or remediation SLA is
offered for this demonstration.

## Scope reminders

- Never include a real OpenAI key, Cloudflare credential, or production secret.
- Test only systems and accounts you own or are explicitly authorized to test.
- Do not access, alter, retain, or disclose another person's data.
- Automated high-volume testing and denial-of-service testing are out of scope.
